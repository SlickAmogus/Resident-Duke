# Contributing

Resident Duke is a fork of Drelvak's Resident Doom; gameplay fixes that also apply upstream are best offered there too. Pull requests to this fork are welcome at the maintainer's discretion.

Do not submit copyrighted proprietary game assets, game executables, GRPs, IWADs, converted game models/audio/art, animation dumps or generated playable packages. Keep changes scoped to the E1L1 prototype. Preserve upstream notices and identify any third-party code you adapt.

Contributions must be compatible with this project's GPL-3.0-only license. No contributor is granted repository write/admin access by submitting a contribution.
